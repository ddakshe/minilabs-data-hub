# 고교별 대학 진학 실적 — 손으로 넣는 데이터

이 폴더만 사람이 채운다. 나머지 `school-zones/*.json` 은 전부
`npm run fetch:school-zones` 가 학구도 공공데이터에서 자동으로 만든다.

**왜 손으로 넣나.** 고교별 대학 진학 실적은 학교알리미 공시항목 62개 어디에도 없다(실측).
대학이 국정감사에 제출한 자료를 언론이 보도하는 게 사실상 유일한 공개 경로고, 연 1회다.

## 파일 하나 = 대학 하나 × 연도 하나

파일 이름은 `<연도>-<대학키>.json` (예: `2026-snu.json`, `2026-yonsei.json`).
서울대만 넣어야 하는 건 아니다. 다만 대학마다 공개 수준이 크게 다르다 —
서울대는 매년 상위권 고교가 공개되지만 연·고대는 거의 공개하지 않는다.

## 넣는 순서

1. 기사나 국정감사 자료의 표를 **텍스트 파일에 그대로 붙여넣는다.**
   순번·탭·`휘문고` 같은 축약이 섞여 있어도 된다.

   ```
   1 경기고등학교 62
   2 휘문고	54
   ```

2. 학교명을 `schoolId` 로 바꾼다.

   ```bash
   node scripts/build-admissions.mjs --resolve list.txt > school-zones/seed/2026-snu.json
   ```

   **동명이교가 1,066건이라 이 단계를 건너뛰면 안 된다.** 세화고는 서울·제주·포항 셋이고
   기사에는 "세화고"라고만 나온다. 이름이 겹치면 후보를 주소와 함께 보여주고 멈추므로,
   맞는 `schoolId` 를 직접 골라 넣는다.

3. 파일 안의 `TODO` 를 전부 채운다. 하나라도 남으면 빌드가 죽는다.

4. 합친다.

   ```bash
   npm run build:admissions      # seed/*.json → school-zones/admissions.json
   ```

## 필드

| 필드 | 뜻 |
|---|---|
| `university` / `universityKey` | 표시명 / 앱에서 쓰는 키 (`snu`, `yonsei`, `korea`) |
| `year` | 입학연도 (정수) |
| `basis` | **집계 기준.** 합격자냐 등록자냐, 수시+정시 합산인지, 재수생 포함인지. 이게 없으면 대학끼리도 연도끼리도 비교할 수 없다 |
| `source` / `sourceUrl` | 출처. 표시 의무가 있다 |
| `coverage` | `partial` (상위 일부만 공개) 또는 `full` |
| `schools[]` | `{ schoolId, name, count }` — `name` 은 사람이 읽기 위한 것이고 조인은 `schoolId` 로만 한다 |

## 앱이 지켜야 할 두 가지

- **미공개는 0이 아니다.** 목록에 없는 학교를 "0명"으로 그리면 통계가 거짓말이 된다.
  `coverage: 'partial'` 이면 "미공개"로 표기한다.
- **`basis` 가 다르면 합산하지 않는다.** 대학을 나란히 놓을 때 기준이 다르면 따로 보여준다.
